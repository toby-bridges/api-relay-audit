Comparison

api-relay-audit vs hvoy.ai vs cctest.ai

These tools answer related but different questions. API Relay Audit is a local, open-source, repeatable audit script. hvoy.ai is useful for relay lookup and public relay observations. cctest.ai focuses on low-friction web checks and Claude-oriented channel fingerprinting claims. The right choice depends on whether you need discovery, convenience, or local evidence.

Short answer: use API Relay Audit when you need a local Markdown report for your own relay route. Use relay lookup surfaces when you need public discovery. Use web checkers when convenience matters more than adding another service to the key path.

Where API Relay Audit is intentionally different

  • It runs locally, so a separate checker server is removed from the audit path.
  • It produces a Markdown report that can be reviewed, redacted, attached to issues, or archived with a test case.
  • It keeps `inconclusive` separate from `clean`, which matters when relays block probes or do not support a protocol.
  • It maps important probes to relay supply-chain risks such as AC-1, AC-1.a, and AC-2.
  • It avoids relay recommendation language. The output is evidence under one run, not a public safe/unsafe ranking.

Not a winner-takes-all claim

Use the tool that matches the question. If you want public relay discovery, a reputation surface may be useful. If you want a local report for your own key, route, and workflow, run API Relay Audit. If you need channel-fingerprint research, track the design memo and implemented channel-classifier work before treating a claim as a production detector.

The comparison should stay current. External tools change, and public launch copy should not freeze old claims about their coverage, pricing, or internals. When in doubt, describe API Relay Audit's current scope rather than over-describing another tool.

FAQ

Should API Relay Audit replace relay reputation lookup?

No. Lookup surfaces help discovery. API Relay Audit helps verify a specific route locally.

Should a web checker replace a local audit?

Only if the convenience tradeoff is acceptable for your threat model. For sensitive keys, local evidence is usually easier to reason about.
