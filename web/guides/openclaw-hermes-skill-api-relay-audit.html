Retained Integrations

OpenClaw and Hermes integration files

API Relay Audit retains its existing OpenClaw and Hermes skill files for direct users and downstream compatibility. Active distribution and release verification now focus on the DeepSeek Harness plugin.

The skill does not certify that a relay is safe. It helps an agent run the same local 14-step audit and keep API-key handling explicit.

Current status

The files remain available at root SKILL.md and skills/api-relay-audit/SKILL.md. They are compatibility artifacts, not current registry publication targets or release blockers.

Primary plugin distribution

For the release-tested agent integration, use the DeepSeek Harness plugin guide. It covers immutable installation, Claude runtime boundaries, per-invocation credential resolution, and connectivity validation.

Why this helps agent safety

  • The audit runs locally rather than through another web checker.
  • The report distinguishes `clean`, `anomaly`, and `inconclusive` results.
  • Tool-call rewriting and Web3 wallet probes are visible before the agent trusts a relay path.
  • The retained files do not imply registry publication or platform endorsement.
