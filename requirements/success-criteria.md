# Success Criteria

## Product and measurement

- A documented value model distinguishes value, proxy, and vanity metrics.
- Google Search Console is configured after a verification token is available.
- Website events are defined before implementation.
- Event QA proves that no sensitive fields are transmitted.
- At least 5 potential participants are recruited and at least 2 observed tests are completed in Week 1.

## SEO and GEO

- A current site inventory covers every indexable public page.
- A fixed English query set is used to establish the SEO opportunity model.
- A fixed GEO prompt set is measured at Weeks 1, 4, 6, and 8.
- Mention, citation, absorption, referral, and product usage remain separate metrics.

## Agentic Growth Automation

- One recurring workflow includes a trigger, deterministic processing, an LLM judgment step, QA, human approval, execution, and feedback.
- The workflow logs failures and supports retry or rollback.
- One core workflow is rerun with a second model using the same specification and evaluation criteria.

## Owner capabilities

By the end of the program, the owner can personally:

1. Define the target user and core value event.
2. Explain the semantics and limitations of each key metric.
3. Design a search-intent and GEO measurement framework.
4. Interview users and synthesize evidence.
5. Prioritize growth interventions.
6. distinguish observation, proxy evidence, directional evidence, and causal evidence.
7. Set automation and publication boundaries.
8. Run a weekly growth review.

## Non-goals

The program is not completed by publishing a high volume of content, collecting GitHub stars, increasing page views alone, or producing agent-generated reports without owner verification.
