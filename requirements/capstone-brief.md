# Capstone Brief

**Status:** Accepted  
**Project:** API Relay Audit  
**Primary market:** Global English-language search  
**Primary users:** AI API relay users and relay operators

## Product

API Relay Audit is an evidence-first, locally executed security audit tool for third-party AI API relays and LLM proxies.

## Core user value

Relay users can collect structured evidence before trusting a relay with coding agents, production workflows, or sensitive operations. Relay operators can identify compatibility, integrity, and transparency problems through reproducible tests.

## Core value event

A user successfully completes an audit and correctly understands or acts on the resulting evidence.

## Candidate North Star

**Weekly Successful Audit Users:** distinct users who complete an audit and demonstrate correct understanding of the report's findings and limitations.

This metric is initially only partially observable. Website actions such as copying a command are proxy metrics, not the North Star itself.

## Eight-week objectives

1. Establish measurable acquisition and activation baselines.
2. Configure a privacy-safe measurement layer for the public website.
3. Establish SEO and GEO baselines.
4. Interview 5–10 relay users and operators.
5. Publish evidence-rich English content based on verified user problems.
6. Build a human-reviewed Agentic Growth workflow.
7. Produce reusable Casebooks and Playbooks.
8. Demonstrate model-orthogonal execution of one core workflow.

## Learning constitution

- **Project-based:** every concept must change the real project or produce reviewable evidence.
- **AI-native:** agents may research, implement, review, and summarize; the owner retains problem definition, evidence judgment, approval, and accountability.
- **Model-orthogonal:** specifications, schemas, tests, and decision records must survive a model change.
