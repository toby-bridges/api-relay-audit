# v2.3.1: Prompt extraction false-positive fix

API Relay Audit v2.3.1 is a focused patch release. It improves refusal
handling without changing the 14-step audit surface, runtime profiles, threat
taxonomy, risk matrix, or Claude stream-identity baseline.

## What Changed

- Normalize common Unicode apostrophes before matching refusal phrases.
- Treat explicit refusals containing weak words such as `assistant`,
  `developer`, or `system prompt` as non-leaks in Step 4.
- Keep structural prompt disclosures and strong markers such as `kiro` or
  `hidden_prompt` actionable even when refusal language is also present.
- Preserve self-corrected Test C output as a review signal rather than a
  confirmed prompt leak.

This fix was derived from [#78](https://github.com/toby-bridges/api-relay-audit/pull/78)
by [@techotaku39](https://github.com/techotaku39).
